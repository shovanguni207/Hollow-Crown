Grimwar is a browser-based visual development environment for creating, editing, and playtesting interactive stories and branching narratives. It combines a playable story engine with the Grimoire, an integrated authoring workspace where creators can visually build and navigate story graphs, edit passages and choices, manage narrative state such as items and other story elements, and playtest their work without leaving the editor. Built with vanilla HTML, CSS, and JavaScript, Grimwar is designed to make complex interactive narratives easier to build, visualize, manage, and experience.
